# VICTORIOUS CHILDREN SCHOOL — UI/UX DESIGN BRIEF

**Version:** 2.0

## 1. Design Objective
Create a premium, trustworthy and welcoming Nigerian school experience communicating excellence, trust, academic seriousness, warmth, discipline, community, faith and modern administration.

## 2. Brand
**VICTORIOUS CHILDREN SCHOOL**  
**OJODU • LAGOS**  
*Not to Equal, But to Excel*

## 3. Colors
- Primary Blue `#1A237E`
- Gold `#C9A84C`
- Red `#B22234`
- Cream `#F8F4E8`
- White `#FFFFFF`
- Dark Text `#1A1A2E`

Use colors deliberately.

## 4. Typography
Use strong, readable headings and a clean body font. Keep font families limited. Motto may be italicized.

## 5. Public Navigation
Home, About, Academics, Admissions, Fees, News, Gallery, Contact.

Primary actions: Apply Now, Pay Fees, Check Results, Portal Login.

## 6. Homepage
Header → Hero → primary actions → introduction → statistics → why VCS → academic levels → admissions CTA → news/events → gallery/community → portal CTA → footer.

## 7. Dashboard UX
Use navigation, header, page title, status/context, primary content and secondary actions. Prioritize information over decoration.

## 8. Admin UX
Tables, search, filters, bulk actions, statuses, confirmations and audit visibility. Prefer archive/status over destructive deletion.

## 9. Teacher UX
Fast attendance and results workflows:
```text
Select class -> date -> mark -> save
Select session -> term -> class -> subject -> enter -> validate -> draft -> submit
```

## 10. Parent UX
Parents should quickly answer: what does my child owe, what are the results, what is attendance, what assignments exist and what announcements matter?

## 11. Student UX
Quick access to timetable, assignments, results, attendance, resources and announcements.

## 12. Forms
Labels, required indicators, validation, meaningful errors, loading/success states and appropriate protection from accidental loss.

## 13. Tables
Readable on tablets, searchable/filterable where needed, paginated and responsive.

## 14. Payments
Clearly show amount, student, purpose, provider, status, reference and receipt. Never show verified success before server verification.

## 15. Results
Show CA, exam, total, grade and approved remarks/cumulative information. Distinguish Draft, Submitted, Approved and Published.

## 16. Faith Integration
Tasteful, consistent Christian-school identity. Avoid making every screen visually religious.

## 17. Motion
Subtle transitions and loading/success states. Respect reduced-motion preferences.

## 18. Responsive Requirement
Primary targets are desktop/laptop and tablet. Smaller screens should still degrade gracefully.

## 19. Visual Quality Gate
Check spacing, alignment, typography, responsive behavior, loading, empty states, errors, success states, accessibility and consistency before completion.
